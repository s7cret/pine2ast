# Pine2AST documentation

Canonical documentation for the Pine2AST 4.0.0 frontend release line.

## Documents

| File | Purpose |
|---|---|
| `ARCHITECTURE.md` | Lexer, parser, AST, diagnostics, semantic passes, and module ownership. |
| `COMPATIBILITY.md` | Pine v5/v6 support profile, builtin coverage, release-feature matrix, and non-goals. |
| `OPENPINE_CONTRACT.md` | Metadata emitted for OpenPine inspection, strategy registration, and downstream validation. |
| `DEVELOPMENT.md` | Local setup, core checks, signature checks, optional checks, and documentation policy. |
| `RELEASE_4_0.md` | 4.0.0 release notes, contract compatibility, runtime boundary, and GitHub tag checklist. |
| `ROADMAP.md` | Stabilization and planned frontend/static-semantics work after 4.0.0. |
| `SECURITY.md` | Resource limits, parser safety model, and integration guidance. |

## Reading order

For new contributors: `ARCHITECTURE.md` -> `COMPATIBILITY.md` -> `OPENPINE_CONTRACT.md` -> `DEVELOPMENT.md`.

For release work: `DEVELOPMENT.md` -> `RELEASE_4_0.md` -> `SECURITY.md`.
